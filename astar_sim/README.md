# A-star simulacija

Simulacija klikom na gumb `Browse image` iz odabrane .yaml datoteke prima početnu vrijednost točaka `start` i `goal` te raspored prepreka na mapi. Klikom na gumb `Draw map` ih crta u grafičkom sučelju. Potom se klikom na gumb `Calculate path` u mapu ucrtava optimalni put od točke start do točke goal. Pozicije start i goal moguće je promijeniti klikom na odgovarajući gumb i zatim odabirom nove pozicije klikom na mapu.

## Pokretanje

Za pokretanje simulacije pozicionirati se terminalu u direktorij /astar-sim te pokrenuti naredbu:

```bash
python3 gui.py
```
